## Gotchas

- [a-failed-import-is-cached-and-not-retried](gotchas/a-failed-import-is-cached-and-not-retried.md) — a failed `EditorImportPlugin` import writes its sidecar with the current `importer_version` and `valid=false`, and `--import` skips it until the source or the version changes; deleting `.godot/imported` does not retry it. An importer that loads other imported files runs after them (`_get_import_order`). Measured in 4.7.2.
- [rect2-intersects-is-false-for-rects-that-only-share-an-edge](gotchas/rect2-intersects-is-false-for-rects-that-only-share-an-edge.md) — `intersects()` ignores shared edges (hence `RoomResidency.touches` grows 1 px), `has_point()` is half-open (a seam point belongs to the lower room), `merge()` is a bounding box that covers an L's empty corner.
- [zigzag-ledges-two-rows-apart-seal-a-shaft](gotchas/zigzag-ledges-two-rows-apart-seal-a-shaft.md) — in a `.room` shaft, ledges on alternating sides need 3 rows between them (96 px rise): 2 rows leave a 32 px corner gap and Ivo is 54 px tall. A stone ledge over a drop hole caps a jump up it: use `=`. Measured 2026-10-10 on the village cistern.
- [an-explicit-process-mode-escapes-a-disabled-ancestor](gotchas/an-explicit-process-mode-escapes-a-disabled-ancestor.md) — a node with its own PAUSABLE or ALWAYS mode keeps ticking under a DISABLED ancestor; `Room.deactivate()` holds `AmbientMotion` and `ForegroundPiece` only by hiding the contents (their `is_visible_in_tree()` early return). Measured in 4.7.2.
- [a-tween-runs-after-every-process-so-a-process-mirror-is-a-frame-late](gotchas/a-tween-runs-after-every-process-so-a-process-mirror-is-a-frame-late.md) — idle tweens step after every node's `_process` (tree order and `process_priority` do not change this), so a node mirroring a tweened value in `_process` copies last frame's value, and the frame is drawn with the new one. Physics tweens and `_physics_process` writes land in time; `RenderingServer.frame_pre_draw` is after everything. Measured in 4.7.2.
- [a-tool-script-cannot-call-methods-on-a-non-tool-resource](gotchas/a-tool-script-cannot-call-methods-on-a-non-tool-resource.md) — in the editor a non-tool custom Resource is a placeholder: a `@tool` node can read its exports, and statics of non-tool classes still work, but any method call errors. Only an editor run shows it (`--headless --editor ... --quit-after`). Measured in 4.7.2.
- [glsl-floor-division-modulo-can-return-the-divisor](gotchas/glsl-floor-division-modulo-can-return-the-divisor.md) — `v - n * floor(float(v) / float(n))` may return `n` at exact multiples (shader division is allowed 2.5 ULP); exact only for power-of-two `n`. - [disabling-a-body-inside-its-own-physics-step-errors-its-move](gotchas/disabling-a-body-inside-its-own-physics-step-errors-its-move.md) — `process_mode = DISABLED` (disable_mode REMOVE) inside a CharacterBody2D's own `_physics_process`, or in a handler of a signal it emits there, takes it out of the space at once; the `move_and_slide()` that follows logs `body->get_space() is null` and leaves `is_on_floor()` false. No `callback_lock` warning outside the flush. Use `set_deferred`. Measured in 4.7.2.
- [a-typed-loop-variable-fails-on-a-freed-object](gotchas/a-typed-loop-variable-fails-on-a-freed-object.md) — `for x: Object in dict.keys()` (or `var o: Object = freed`) errors `Trying to assign invalid previously freed instance` on the assignment, so an `is_instance_valid()` inside the loop is never reached; untyped and `Variant` slots are fine, and a freed object `== null` is true. Measured in 4.7.2.
- [parallax2d-ignores-its-parents-offset](gotchas/parallax2d-ignores-its-parents-offset.md) — `Parallax2D` sets its local position to `screen_offset * (1 - scroll_scale) + scroll_offset` from the camera's GLOBAL offset, so under a region placed at x 7200 its layers drift `(1 - scroll_scale) * 7200` px; the trials' sky and mountain layers are off screen.
