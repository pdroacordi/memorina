## Gotchas

- [gui-focus-skips-a-neighbour-wholly-clipped-by-a-scroll-container](gotchas/gui-focus-skips-a-neighbour-wholly-clipped-by-a-scroll-container.md) — `ui_up`/`ui_down` focus search does not reach a control wholly outside a ScrollContainer's visible rect when the focused control is flush with that edge; a partly visible neighbour is reached. Measured headless in 4.7.2; `grab_focus` tests never see it.
- [a-control-is-culled-by-its-own-rect](gotchas/a-control-is-culled-by-its-own-rect.md) — a Control's canvas item is culled by `Rect2(0, size)`, not by what `_draw` draws, so a pannable canvas drawn from a Control vanishes once its own rect leaves the screen; draw it from a Node2D (UI-04 `MapCanvas`).
- [a-teleported-kinematic-body-overlaps-from-its-old-place-for-one-step](gotchas/a-teleported-kinematic-body-overlaps-from-its-old-place-for-one-step.md) — a moved CharacterBody2D is still at its old place for the next step's Area2D pairs; `body_set_state(TRANSFORM)` does not help, a `STATIC` → set transform → `KINEMATIC` toggle applies it at once (measured 4.7.2). Adopted as `Character.teleport`.
- [time-scale-zero-stops-delta-particles-and-time](gotchas/time-scale-zero-stops-delta-particles-and-time.md) — at `Engine.time_scale = 0` (a menu hold) every delta is exactly 0, `CPUParticles2D` and shader `TIME` stop, and only `set_ignore_time_scale(true)` tweens move; ALWAYS audio keeps playing. Measured in 4.7.2.
- [csv-translations-unescape-backslash-n](gotchas/csv-translations-unescape-backslash-n.md) — a literal `
` in `translations.csv` becomes a newline; a real line break splits the row.
- [gui-focus-moves-once-per-stick-tilt](gotchas/gui-focus-moves-once-per-stick-tilt.md) — the engine's `ui_*` focus navigation moves once per stick tilt through `Input.parse_input_event`, and not at all through `Viewport.push_input`; a script reading `is_action_pressed` still sees every motion. Measured in 4.7.2.
- [a-menu-press-reaches-the-last-node-first](gotchas/a-menu-press-reaches-the-last-node-first.md) — `_input` runs in reverse tree order and stops at `set_input_as_handled()`, and paused nodes are skipped rather than queued, so `ScreenLayer` must stay after `World`. A `Button` acts on the `ui_accept` release, and that release then reaches the `_unhandled_input` (not `_input`) of the nodes it just unpaused. Measured in 4.7.2. `InputDevice` listens on `root.window_input` so handled presses still switch the glyphs.
- [a-stick-is-pressed-on-every-motion-event](gotchas/a-stick-is-pressed-on-every-motion-event.md) — `is_action_pressed` is true for every joystick motion past the deadzone, so a press signal from a stick-bound action must be an edge (`PlayerInput._down_held`); a held stick re-sat Ivo after every stand-up. A motion event is the pad too (`glyph_set_for`).
- [first-process-frame-can-precede-the-first-deferred-flush](gotchas/first-process-frame-can-precede-the-first-deferred-flush.md) — at boot `process_frame` is emitted before the idle flush and the first iteration may run no physics step, so `call_deferred` + one `await process_frame` in the main scene's `_ready` is not guaranteed (measured 4/5 headless in a minimal project); `Game._arrive` now awaits the room contents' `ready` instead (2026-10-01).
- [queue-free-deferred-add-still-enters-the-tree](gotchas/queue-free-deferred-add-still-enters-the-tree.md) — the deferred flush runs before the delete queue, so a node `queue_free()`d while its `call_deferred("add_child")` is pending still enters the tree (ready, groups) for the frame; `Room` now defers its own `_add_contents`, which skips contents evicted meanwhile (2026-10-01).
- [sync-to-physics-lands-a-move-next-step](gotchas/sync-to-physics-lands-a-move-next-step.md) — a moving platform's set transform reads back stale until the next physics step; keep the target as state and test that.
- [body-state-cannot-change-in-the-physics-flush](gotchas/body-state-cannot-change-in-the-physics-flush.md) — `freeze`/`disabled` set from an area signal is refused; defer it.
- [playtest-clock-pauses-with-the-tree](gotchas/playtest-clock-pauses-with-the-tree.md) — a timeline's `t` is unpaused time; a performance's frozen seconds do not count.
- [a-force-does-not-wake-a-sleeping-rigidbody](gotchas/a-force-does-not-wake-a-sleeping-rigidbody.md) — wake it yourself; and cut a sliding box's corners so tile seams do not stop it.
- [import-plugin-output-is-stale-when-its-logic-changes](gotchas/import-plugin-output-is-stale-when-its-logic-changes.md) - an import is redone only when its source or `_get_format_version()` changes; the `.room` importer bakes `GroundAutotile`, the parser and the legend in, so changing them leaves every machine's imported maps stale while `room_files_test` stays green.
- [logger-log-error-also-receives-warnings](gotchas/logger-log-error-also-receives-warnings.md) - a custom `Logger._log_error` also receives `push_warning` (`error_type` 1); the smoke test counts warnings as failures.
- [duplicate-copies-script-built-unowned-children](gotchas/duplicate-copies-script-built-unowned-children.md) - `duplicate()` copies children whatever their owner, so a node that builds in `_ready` gets two sets; "unowned, never saved" is true for scene saves only.
- [queue-free-keeps-the-name-until-frame-end](gotchas/queue-free-keeps-the-name-until-frame-end.md) - a queued node keeps its name until the frame ends; a same-frame replacement becomes `@Type@N` for good. `remove_child` first.
- [tileset-padding-bakes-only-defined-tiles](gotchas/tileset-padding-bakes-only-defined-tiles.md) - texture padding bakes only defined tiles, so a seasonal band with no defined tiles samples transparency and the ground vanishes under another season's pulse.
- [lake-hidden-under-a-tilemaplayer-parent](gotchas/lake-hidden-under-a-tilemaplayer-parent.md) - a lake built as a child of the ground TileMapLayer stopped drawing; build water and entities as siblings of the tiles.
- [a-freed-object-in-a-deferred-call-fails-its-typed-argument](gotchas/a-freed-object-in-a-deferred-call-fails-its-typed-argument.md) — `call_deferred(node)` with `node` freed before the flush errors on a typed parameter before the method runs; store it in a field and defer a call with no arguments (UI-03 list framing).
- [autowrapped-rows-settle-over-several-sorts](gotchas/autowrapped-rows-settle-over-several-sorts.md) — autowrapped Labels in a VBox report tall, then final heights a sort or more later; read row geometry on `sort_children`, not one deferred call later (measured 4.7.2).
- [a-script-run-with-s-cannot-compile-classes-that-name-autoloads](gotchas/a-script-run-with-s-cannot-compile-classes-that-name-autoloads.md) — a `-s` SceneTree script cannot name autoloads or type a variable as a class that does; use `root.get_node()` and untyped variables.
- [a-killed-tween-never-emits-finished](gotchas/a-killed-tween-never-emits-finished.md) — `kill()` never emits `finished`; `Fade` kills its previous tween, so two overlapping awaiters of `Fade` leave the first suspended for ever.
- [monitorable-false-hides-an-area-from-every-monitor](gotchas/monitorable-false-hides-an-area-from-every-monitor.md) — i-frames keyed as `Hurtbox:monitorable` hide the body from EVERY area (hazards, triggers), not just hitboxes; flicker reports exit + re-enter. Detect the body for "is here" triggers.
- [tilemaplayer-enabled-does-not-hide-children](gotchas/tilemaplayer-enabled-does-not-hide-children.md) — `TileMapLayer.enabled = false` removes only the layer's own tiles (quadrants, collision, scene tiles). Nodes `add_child()`ed under it keep drawing and processing, which `WaterLayer` relies on. `visible = false` would hide them too.
- [screen-texture-copy-scope](gotchas/screen-texture-copy-scope.md) — the automatic screen copy is retaken per canvas layer (no `BackBufferCopy` needed) but shared by every reader on one layer; also records the water spikes: the derivative-scaled world-space mirror holds at every zoom, the creature pass is current-frame, a `blend_mul` veil keeps alpha.
- [sprite-frame-out-of-bounds-on-clip-switch](gotchas/sprite-frame-out-of-bounds-on-clip-switch.md) — jumping from a wider strip to a narrower one logs `Index p_frame out of bounds` for a tick; pre-existing, cosmetic, candidate fixes listed.
- [subviewport-does-not-inherit-default-texture-filter](gotchas/subviewport-does-not-inherit-default-texture-filter.md) — a `SubViewport` defaults to LINEAR filtering whatever the project setting says; set `canvas_item_default_texture_filter` on every one.
- [animationtree-reset-track-overwrites-script-writes](gotchas/animationtree-reset-track-overwrites-script-writes.md) — a script write to any property with a `RESET` track is silently undone every frame.
- [glsl-gdscript-math-must-be-duplicated](gotchas/glsl-gdscript-math-must-be-duplicated.md) — GDScript and GLSL cannot share code; `MemoryFieldMath` and `greyhush_common.gdshaderinc` must be edited in lockstep.
- [physics-parent-before-children-one-frame-lag](gotchas/physics-parent-before-children-one-frame-lag.md) — Godot processes parents before children, so caching continuous input in `_physics_process` reintroduces a one-frame lag.
- [input-action-press-does-not-reach-input-callbacks](gotchas/input-action-press-does-not-reach-input-callbacks.md) — `Input.action_press()`/`action_release()` only set polled state; use `Input.parse_input_event()` to also fire `_input()`.
- [scene-resave-buries-real-edits-in-noise](gotchas/scene-resave-buries-real-edits-in-noise.md) — a `.tscn` resave mixes real property edits (a moved node) into a diff full of harmless editor metadata churn.
