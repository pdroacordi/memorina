The shared preamble every PixelLab prompt in this library is appended to
(tools/pixellab/pixellab.ps1 -Prompt). Change it here, never per entry, so the
whole game keeps one look. The world it must match: the GandalfHardcore
platformer tiles and backgrounds under assets/sprites/world/, dark soil with a
seasonal top (spring grass, autumn leaves, winter frost), and the greyhush
that empties colour from forgotten places - art should read in silhouette and
value, because a forgotten pixel keeps only those.
